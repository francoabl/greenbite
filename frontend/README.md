# GreenBite Frontend

Frontend en React + Vite para GreenBite. Consume el BFF y muestra planes de suscripcion y pedidos.

## Requisitos
- Node.js 18+

## Configuracion
Crear un archivo .env con:

```
VITE_BFF_URL=http://localhost:4000
```

## Instalacion
```
npm install
```

## Desarrollo
```
npm run dev
```

## Build
```
npm run build
npm run preview
```

## Pruebas
```
npm run test
```
