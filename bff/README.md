# GreenBite BFF

Backend For Frontend (BFF) que centraliza el acceso a microservicios de usuarios y pedidos.

## Requisitos
- Node.js 18+

## Configuracion
Crear un archivo .env con:

```
PORT=4000
USUARIOS_SERVICE_URL=http://localhost:4001
PEDIDOS_SERVICE_URL=http://localhost:4002
```

## Instalacion
```
npm install
```

## Desarrollo
```
npm run dev
```

## Produccion
```
npm start
```
